# Contributing

Thanks for looking at Ephemeral Chat. It is a personal project, so I answer
when I can.

**Everything here is in English**: discussions, issues, pull requests,
commits, code, names and documents.

## Ideas and questions

Start a [discussion](https://github.com/esteban-abanto-2709/ephemeral-chat/discussions).
Everything is open to debate there, even the
[principles](./docs/product-vision.md#principles) the product is built on.
Wild ideas are welcome.

## Issues

Issues are for bugs and for changes that fit the four principles. An idea
that changes a principle starts as a discussion.

- One problem per issue.
- Be specific: what happened, how to see it, what you expected.
- Keep it short.

## Pull requests

Open a pull request only for an issue where we agreed on the change first. A
pull request without one is closed with a link to this page.

- One issue, one pull request.
- Touch as little code as possible: no refactors, renames or reformatting
  outside the change.
- CI must pass.
- Follow the conventions in [`CLAUDE.md`](./CLAUDE.md) and, for the web, in
  [`docs/angular.md`](./docs/angular.md).

To run the project, see [Run it on your machine](./README.md#run-it-on-your-machine)
and the README of each app.
