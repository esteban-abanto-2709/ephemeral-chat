# Roadmap

Committed work: what will be done. Code `RM-###` (never reused).
Ordered by priority, top first. When a task is finished it moves to the
changelog and is deleted from here.

**Entry format:**
- **Goal:** what we want to achieve.
- **Scope:** (optional) what's in and what's out.
- **Open questions:** (optional) what must be decided when starting.
- **Done when:** clear completion criterion.
- **Date** and **Status** (Open / In progress).

---

Each entry is one commit, or a few when it spans both apps; no commit breaks production.

## [RM-010] Comfort (v0.3)
- **Goal:** make the room pleasant to use every day, above all on a phone.
- **Scope:** the room redesign approved on `/design` (clear background, glass bubbles, floating header and composer, no green fill); keyboard handling on iOS and Android; an installable PWA without a service worker; the typing indicator (WL-001) in the API and the web.
- **Done when:** all four are in production and `package.json` is at 0.3.0.
- **Date:** 2026-11-04 · **Status:** In progress (2026-11-04)
